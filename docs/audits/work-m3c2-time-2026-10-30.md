# Work M3-C2 — manual Time and CAS correction

Date: 30 October 2026
Branch: feature/work-m3-operations-foundation-20261030
Classification: SOURCE implementation. Level 1, Level 2, Level 3 and FIELD remain HOLD.

Managers now add manual entries and correct **their own completed entries** from the Work Time panel using Base Modal. Dedicated REST routes recheck MANAGE, runtime and schema, actor ownership, canonical Time Access and existing TimeRange local-to-UTC conversion. Seconds and unchanged DST-fold instants survive corrections; ambiguous new times are rejected; manual zero duration is rejected and unchanged stopped timer zero duration remains governed by the repository. Writes delegate to TimeEntries::create_manual and TimeEntries::update_completed (CAS revision). New audit events are emitted only after successful writes; HTTP 409 requires reopen, with no automatic replay.

Manager cross-user edits, bulk updates and full filtering, as well as tracker-only Time, remain in native Time. The Work panel supplies native fallback if Base Modal is unavailable. No database/schema/Base change and no legacy screen removed.

M3-C2 PHP source, PHP REST runtime (18 guarded assertions) and Node Base Modal runtime fixtures are enrolled in tools/check. The new ESM module is staged with content-addressed module imports. A separate isolated V8 modal model check against fetched source passed create, correction, 409 conflict and teardown; this is not a canonical Level 1/2 or browser FIELD pass.
